# TradingView Built-in Technical Indicators

检索日期：2026-08-27

## 范围

本清单来自 TradingView 官方 [Supercharts](https://www.tradingview.com/chart/) 的实际指标弹窗，路径为：

`Built-in → Technicals → Indicators`

抓取时 `Indicators` 标签处于选中状态；`Strategies`、`Profiles`、`Patterns`、
`Fundamentals` 和 `Community` 均不在本清单内。共取得 **127 项**，名称和顺序均保留官网
英文 UI 原文。

`NEW`、`BETA`、`UPDATED` 是抓取时官网显示的状态标签，不属于指标名称。

## 范围差异

- TradingView 官方说明，内建脚本位于指标弹窗的 `Technicals` 组，并与 Community
  Scripts 分开。参见 [I want to see the source code of a built-in script](https://www.tradingview.com/support/solutions/43000481659-i-want-to-see-the-source-code-of-a-built-in-script/)。
- [Advanced Charts / Trading Platform Indicators List](https://www.tradingview.com/charting-library-docs/latest/ui_elements/indicators/Indicators-List/)
  是嵌入式图表库的另一份 107 项清单，不等于 TradingView 官网 Supercharts 当前的
  127 项清单。
- Help Center 的 [Built-in Indicators](https://www.tradingview.com/support/folders/43000587405/)
  是帮助文章目录，还包含链上指标等更广内容，也不等于上述官网 UI 清单。
